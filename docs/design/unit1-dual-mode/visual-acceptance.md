Intentional differences: the user required both existing recordings to remain
unchanged. The opening therefore teaches Jake/Pete and the facts actually
heard, instead of the unsupported Peter biography. Extra grammar examples are
identified as practice. Conversation prompts are text, with no invented audio.
Copy is shortened; editable responses start empty rather than with the mockup's
sample answers. The unit contains 18 scenes instead of the original 13 because
five focused teaching/production steps were approved. Sixteen environments are
assigned, with only the three consecutive opening vocabulary scenes sharing
the same setting as one continuous conversation.

Interaction evidence includes expanded grammar and possessive references,
the source reading, automatic choice/listening feedback, fill feedback, and
companion conversation mode. Actual microphone recording and authenticated AI
grading were not submitted from the local public preview; their readiness,
success/failure and cleanup behavior are covered by component tests. Public
dev deployment verification remains a separate release step.

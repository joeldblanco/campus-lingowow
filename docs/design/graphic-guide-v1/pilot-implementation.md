# Aplicación al piloto «This is me!»

La guía se aplica al visor del estudiante para la lección `cmk4otvgp0001w1p4ijdkv6i2`
del curso `cmjnr0g5x0001jp04fsw2fejs`. El resto de las unidades, la vista docente
y el aula conservan sus visores actuales.

## Criterios de revisión

- La unidad se identifica en una cabecera discreta; cada paso tiene un título protagonista.
- El contenido precede a la ilustración en pantallas pequeñas.
- Carl acompaña su lectura; Lucas acompaña los ejemplos que hablan de Lucas.
  Las referencias y las tareas de producción no necesitan retratos decorativos.
- Los posesivos tienen un paso propio y todas las variantes gramaticales permanecen visibles.
- Se conserva el contenido publicado: vocabulario de Peter, lectura completa de Carl,
  audios, preguntas, instrucciones y configuración de las actividades.
- Los campos conservan sus respuestas al retroceder. Cambiar de paso pausa el audio
  oculto y una grabación activa impide abandonar su paso.
- Los controles mantienen sus reglas actuales. La presentación no convierte una
  recomendación de palabras en un nuevo límite ni añade requisitos para avanzar.
- La acción real de la actividad se sitúa en el pie. En verdadero/falso,
  «Comprobar» pasa a «Siguiente» entre preguntas después de mostrar el resultado.
  Continuar la lección sigue disponible como acción secundaria. Los botones de
  evaluación de escritura y grabación conservan sus servicios y sus estados.

## Validación

Las pruebas de componentes verifican jerarquía, contenido, navegación y estados.
Se ejecutan además la suite unitaria, el análisis de estilo y la comprobación de tipos.
La revisión visual y la prueba con estudiantes quedan a cargo del usuario;
no se levanta el servidor local ni se realizan comprobaciones de navegador.

Esta aplicación al piloto no migra automáticamente el catálogo completo de tipos.
Los [mockups v3](../content-format-mockups/v3/README.md) sirven como referencia
para ampliar el formato después de revisar el piloto.
